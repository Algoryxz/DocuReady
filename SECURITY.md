---

## Reporting a Vulnerability

The DocuReady team takes security, privacy, and personal data protection very seriously.

If you discover a security vulnerability (such as a remote code execution via PDF rendering, memory disclosure, denial of service, or improper handling of applicant data), please do **NOT** open a public issue.

Instead, please report it privately:
- **Email**: smarakpadhi58@gmail.com
- **Subject**: `[SECURITY VULNERABILITY] DocuReady - <Brief Summary>`

Please include in your report:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Potential impact and attack scenario.
4. Suggested remediation if available.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure and patch.

---

## Privacy Guarantee

DocuReady executes all document processing, OCR, and validation entirely locally. No document text, image, or metadata is ever transmitted to external servers. Contributed code must maintain this strict zero-exfiltration constraint.
